# Ежедневник (Diary v2)

Личное offline-first PWA-приложение для самодисциплины одного пользователя.

## 🎯 Назначение и цели
Приложение создано как строгий и быстрый персональный инструмент:
1. Сдать HSK 4+ (китайский язык, регулярная практика).
2. Аттестат 11 класса не ниже 4.0.
3. Грант на языковой год в Китае.

Никаких тяжелых фреймворков, никакого стороннего трекинга, только чистый HTML5, CSS3 и Vanilla JavaScript.

---

## 📱 Экраны приложения
1. **«Сегодня»** — шапка ключевых целей, трекер китайского языка (стрик, таймер занятий, выученные слова), таймлайн задач и уроков на день, блок разбора просрочек и вечерний разбор дня с рефлексией.
2. **«Неделя»** — планировщик на неделю (сетка Пн–Вс на десктопе, вертикальный список дней на мобильном), перетаскивание задач (HTML5 Drag-and-Drop), чипы категорий.
3. **«Школа»** — базовое расписание уроков (дни 1–7), расписание звонков, оверрайды на дату (замены), трекер домашней работы с группировкой по срокам.
4. **«Заметки»** — быстрый блокнот без лишней сложности, сортировка по дате создания.
5. **«Настройки»** — редактирование целей и параметров китайского языка, настройка синхронизации, экспорт/импорт JSON и безопасный полный сброс.

## 🚀 Как запустить локально

Поскольку приложение использует Service Worker (PWA) и ES-модули, его необходимо открывать через локальный веб-сервер (по протоколу `http://localhost`):

### Вариант 1 (Node.js):
```bash
npx serve .
# или
npx http-server -p 8080 .
```

### Вариант 2 (Python 3):
```bash
python -m http.server 8080
```

После запуска откройте в браузере: `http://localhost:8080` (или `http://localhost:3000`).

## ☁️ Как задеплоить статику (PWA)

Статические файлы приложения (`index.html`, `styles.css`, `app.js`, `storage.js`, `sync.js`, `toast.js`, `sw.js`, `manifest.json`, иконки и папка `ui/`) не требуют сборки и готовы к размещению на любом статическом хостинге с HTTPS:

- **Cloudflare Pages**:
  ```bash
  npx wrangler pages deploy . --project-name=diary-app
  ```
- **GitHub Pages**:
  В настройках репозитория в разделе *Pages* выберите ветку `main` и корневую папку `/`.
- **Vercel / Netlify**:
  Просто импортируйте репозиторий со стандартными настройками статического сайта.

## 🔄 Как настроить Cloudflare Worker (Синхронизация Телефон ↔ ПК)

Синхронизация выполняется по схеме Last-Write-Wins через один эндпоинт `/state` с авторизацией заголовком `X-Sync-Secret`.

1. Перейдите в папку воркера:
   ```bash
   cd worker
   ```
2. Создайте KV namespace:
   ```bash
   wrangler kv:namespace create STATE_KV
   ```
3. Скопируйте полученный `id` пространства имен в файл `worker/wrangler.toml`:
   ```toml
   [[kv_namespaces]]
   binding = "STATE_KV"
   id = "ВАШ_KV_NAMESPACE_ID"
   ```
4. Установите секретный токен доступа:
   ```bash
   wrangler secret put SYNC_SECRET
   # Введите надежный пароль/токен
   ```
5. Задеплойте воркер:
   ```bash
   wrangler deploy
   ```
6. Воркер выдаст URL (например, `https://diary-sync.<subdomain>.workers.dev`).
7. Откройте «Ежедневник» на телефоне или ПК -> перейдите в **«Настройки»** -> секция **«Синхронизация»**:
   - В поле **URL воркера** укажите: `https://diary-sync.<subdomain>.workers.dev/state`
   - В поле **Секретный ключ** укажите то же значение, что задали в `SYNC_SECRET`.
   - Нажмите **«Сохранить»**, затем **«Синхронизировать сейчас»**.

## 📲 Как установить PWA на Android

1. Откройте развернутое по HTTPS приложение в браузере **Google Chrome** на телефоне.
2. Нажмите на значок меню браузера (**три точки** в правом верхнем углу).
3. Нажмите **«Установить приложение»** (или «Добавить на главный экран»).
4. Подтвердите установку.
5. На главном экране телефона появится иконка **«Ежедневник»** с фиолетовой буквой «Д».
6. Приложение запускается в отдельном окне без адресной строки браузера и работает автономно даже без доступа к интернету.
