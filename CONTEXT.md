# Ежедневник — контекст проекта

## Назначение
Личный инструмент самодисциплины. Один пользователь (владелец). Язык интерфейса — только русский. Никакой мультиязычности, никакого AI, никаких Pomodoro, никакого трекинга здоровья, никакой сложной аналитики.

## Цели пользователя (всегда видны в шапке экрана «Сегодня»)
1. Сдать HSK 4+ (китайский, самообучение).
2. Аттестат 11 класса не ниже 4.0.
3. Грант на языковой год в Китае.

## Экраны (ровно 5)
1. «Сегодня» — таймлайн дня + блок просрочек.
2. «Неделя» — сетка Пн–Вс, планирование задач.
3. «Школа» — расписание (базовое + оверрайд на дату) + звонки + домашка.
4. «Заметки» — простой список.
5. «Настройки» — цели, китайский, синк, экспорт/импорт, сброс.

## Правила поведения
- Утром пользователь открывает «Сегодня» и видит готовый список: задачи на сегодня + домашка с dueDate = сегодня + просрочки.
- Просрочки (task.date < today и !done; homework.dueDate < today и !done) — отдельный блок с кнопками [✓ Готово] [→ На завтра] [✕ Удалить].
- Планирование недели — в сб/вс. Если следующая неделя не в weekPlan.plannedWeeks — баннер «Спланируй следующую неделю».
- Разбор дня — блок на «Сегодня» после 20:00 (и по кнопке): список выполненных + поле «1 строка рефлексии» → reviews.
- Streak по китайскому: если за сегодня minutes > 0 и это новый день — streak++, lastStudyDate = today. Иначе streak не растёт; сброс — если вчера не занимался.
- Домашка: отдельная вкладка в «Школе», но на «Сегодня» попадает автоматически в день dueDate.

## Технические ограничения
- Чистый HTML/CSS/JS, без фреймворков, без библиотек, без сборки.
- Роутинг — hash (#/today, #/week, #/school, #/notes, #/settings).
- Файлы: index.html, styles.css, app.js, storage.js, sync.js, sw.js, manifest.json, папка ui/ (по файлу на экран).
- PWA: устанавливается, офлайн-кэш статики. Пуш-уведомлений нет.
- Синк: Cloudflare Worker, endpoint /state GET/PUT, авторизация заголовком X-Sync-Secret, данные — один JSON.
- Ничего лишнего не добавляй. Если сомневаешься — не добавляй.
